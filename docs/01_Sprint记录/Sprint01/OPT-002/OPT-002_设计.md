## 需求概述

> 作为开发者，我希望warning级别的调用栈显示可以通过配置参数控制，以便在生产环境中关闭调用栈以提升性能。

### 验收标准

- [ ] 新增 `config.logger.show_warning_stack` 参数控制warning级别是否显示调用栈
- [ ] 参数默认值为 `false`
- [ ] 新参数需写回config对象，主程序需调用 `config.save()` 持久化
- [ ] error级别：当没有异常栈时，默认显示调用栈（不受show_warning_stack开关控制）
- [ ] 端到端测试必须通过

---

## 现状分析

**已有实现（OPT-001）**：
- WARNING级别：无条件显示调用栈（使用`traceback.extract_stack()`）
- ERROR及以上级别：使用错误栈（使用`sys.exc_info()`）

**需求分析**：
- WARNING级别需要改为可配置：默认不显示调用栈
- ERROR级别需要增强：无异常栈时显示调用栈

**关联issue**：OPT-001（统一warning及以上级别记录调用栈）

---

## 选定方案

**方案：参数化配置 + ERROR级别调用栈增强**

**核心思路**：
1. 新增 `config.logger.show_warning_stack` 参数（默认False）
2. 修改 `config._ensure_logger_attributes()` 添加默认值
3. 修改 `logger._log()` 方法：
   - WARNING级别：根据配置决定是否显示调用栈
   - ERROR级别：无异常栈时显示调用栈

**理由**：
- 保持向后兼容，默认关闭WARNING调用栈以提升性能
- ERROR级别增强便于调试，不受WARNING开关控制
- 复用OPT-001的`get_call_stack()`函数

## 集成设计

### 接口契约

#### 1. 新增配置属性：config.logger.show_warning_stack
```python
# config.py: _ensure_logger_attributes
_ensure_attribute(logger_obj, 'show_warning_stack', False)
```

#### 2. 新增函数：logger._get_show_warning_stack_config()
```python
def _get_show_warning_stack_config() -> bool:
    """获取WARNING级别是否显示调用栈的配置

    Returns:
        bool: True表示显示调用栈，False表示不显示
    """
    try:
        from .config import _direct_config_object
        logger_obj = getattr(_direct_config_object, 'logger', None)
        if logger_obj is None:
            return False
        if isinstance(logger_obj, dict):
            return logger_obj.get('show_warning_stack', False)
        else:
            return getattr(logger_obj, 'show_warning_stack', False)
    except Exception:
        return False
```

#### 3. 修改逻辑：logger._log()
```python
# 当前逻辑（OPT-001）
exception_info = None
if level_value == WARNING:
    call_stack = get_call_stack()
    if call_stack:
        exception_info = call_stack
elif level_value >= ERROR:
    exception_info = get_exception_info()

# 新逻辑（OPT-002）
exception_info = None
if level_value == WARNING:
    # WARNING级别：根据配置决定是否显示调用栈
    if _get_show_warning_stack_config():
        call_stack = get_call_stack()
        if call_stack:
            exception_info = call_stack
elif level_value >= ERROR:
    # ERROR及以上：优先使用错误栈，无异常栈时显示调用栈
    exception_info = get_exception_info()
    if not exception_info:
        # 无异常栈时，显示调用栈
        call_stack = get_call_stack()
        if call_stack:
            exception_info = call_stack
```
