## 需求概述

> 作为系统管理员，我希望能够配置日志文件的有效期（保留天数），在首次初始化logger系统时，自动删除超过有效期的日志文件，以便控制日志存储空间占用。

### 澄清后的需求

| 需求项 | 说明 |
|:-------|:-----|
| 清理范围 | `config.paths.work_dir/logs` |
| 默认有效期 | 支持配置，默认7天 |
| 配置处理 | 如果没有配置项，赋默认值给config属性，然后 `config.save()` |
| 执行时机 | 启动后第一次清理（每次程序启动时执行一次） |
| 执行位置 | 必须在主进程执行，不能在spawn/fork进程执行 |
| 日期判断 | 根据目录名 `yyyymmdd` 判断过期，删除整个过期目录 |
| 日志记录 | 摘要（仅统计）：记录删除的目录数量和释放的总空间 |

---

## 选定方案

**方案1：内置清理模块**

在 `custom_logger` 包内新增 `log_cleaner.py` 模块，遍历 `config.paths.work_dir/logs` 下的日期目录（格式 `yyyymmdd`），计算距离当前天数，超过 `log_retention_days` 天则删除整个目录。

## 数据链路分析

| 环节 | 输入 | 处理逻辑 | 输出 | 涉及文件 |
|:-----|:-----|:---------|:-----|:---------|
| 1. 配置读取 | config对象 | 读取paths.work_dir、logger.log_retention_days | 配置值 | manager.py, log_cleaner.py |
| 2. 配置初始化 | config对象 | 检查log_retention_days是否存在，不存在则赋值并save | 完整配置 | log_cleaner.py |
| 3. 目录扫描 | work_dir/logs路径 | 遍历子目录，筛选yyyymmdd格式目录 | 目录列表 | log_cleaner.py |
| 4. 日期计算 | 目录名yyyymmdd | 解析日期，计算与当前日期差值 | 天数差 | log_cleaner.py |
| 5. 过期判断 | 天数差、retention_days | 差值 > retention_days 则过期 | 过期目录列表 | log_cleaner.py |
| 6. 目录删除 | 过期目录路径 | shutil.rmtree删除，累加释放空间 | 删除计数、空间统计 | log_cleaner.py |
| 7. 日志输出 | 统计结果 | logger.info输出摘要 | 清理日志 | log_cleaner.py |

## 实现注意事项

1. **仅主进程执行**：使用全局标记 `_cleanup_done` 确保只执行一次
2. **异常处理**：目录删除失败时记录警告，不中断初始化流程
3. **日志目录不存在**：视为正常情况，输出INFO级别日志
4. **config.save()**：只在主进程首次初始化时调用
5. **日期格式严格**：只处理 `yyyymmdd` 格式，其他格式跳过
