## 端到端测试设计

### E2E-001: 正常清理流程

- **场景类型**：正常
- **前置条件**：
  - config.paths.work_dir/logs 存在
  - 包含多个日期目录（yyyymmdd格式）
  - 部分目录超过保留期（7天）
- **测试步骤**：
  1. 初始化日志系统（init_custom_logger_system）
  2. 系统自动执行清理操作
  3. 验证过期目录被删除
  4. 验证未过期目录保留
  5. 验证日志输出正确
- **通过标准**：
  - 过期目录被删除
  - 未过期目录保留
  - INFO日志记录正确的删除数和释放空间

### E2E-002: 无过期目录场景

- **场景类型**：边界
- **前置条件**：所有目录都在保留期内
- **测试步骤**：
  1. 初始化日志系统
  2. 系统执行清理操作
  3. 验证所有目录保留
- **通过标准**：所有目录保留，日志输出"删除0个目录"

### E2E-003: 日志目录不存在场景

- **场景类型**：边界
- **前置条件**：work_dir/logs 不存在
- **测试步骤**：
  1. 初始化日志系统
  2. 验证不影响系统启动
- **通过标准**：系统正常启动，日志输出跳过信息

### E2E-004: 配置项自动初始化

- **场景类型**：正常
- **前置条件**：config对象没有log_retention_days属性
- **测试步骤**：
  1. 初始化日志系统
  2. 验证config对象已更新
- **通过标准**：config.logger.log_retention_days = 7，save()被调用

### E2E-005: 只执行一次

- **场景类型**：边界
- **前置条件**：正常config对象
- **测试步骤**：
  1. 第一次调用init_custom_logger_system
  2. 第二次调用init_custom_logger_system
- **通过标准**：第一次执行清理，第二次跳过
