## 1. 需求背景

> 作为开发者，我希望在 logger 系统初始化成功后，自动通过 logger.info 打印出日志路径信息，以便确认初始化成功并方便定位日志文件位置。

**验收标准**：
- [ ] 初始化成功后自动打印日志路径信息
- [ ] 打印信息包含日志目录和日志文件名
- [ ] 使用 logger.info 级别打印（不是 print）
- [ ] 端到端测试必须通过（禁止跳过端到端测试）

## 2. 现状分析

**涉及模块**：
- `manager.py`：init_custom_logger_system 函数
- `writer.py`：LogWriter 类，日志文件管理
- `config.py`：配置管理，log_dir路径

**现有流程**：
1. 主程序调用 init_custom_logger_system(config)
2. 函数内部调用 init_writer() 初始化异步写入器
3. 创建日志目录和日志文件
4. 返回，完成初始化

**现状**：初始化成功后没有任何输出，用户不知道日志文件创建在哪里。

## 3. 约束集

**硬约束**（必须遵守）：
- [ ] 必须使用logger.info级别打印，不能使用print
- [ ] 打印信息必须包含日志目录路径
- [ ] 打印信息必须包含日志文件名
- [ ] 必须在init_custom_logger_system成功后打印

**软约束**：
- [ ] 打印信息应简洁明了

**明确排除**：
- ❌ 不能使用print输出
- ❌ 不能影响初始化失败时的错误抛出行为
