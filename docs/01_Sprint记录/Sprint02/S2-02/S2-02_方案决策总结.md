## 冻结摘要

- 方案方向不变：`get_caller_info()` 的 Interface 和 Seam 保持，Implementation 从 `inspect.stack()` 改为 `inspect.currentframe()` + raw frame 单次完整扫描。
- `codebase-design` 冻结：`get_caller_info()` 是目标 Module；不新增 Adapter、公共 caller Interface、缓存 Module、第二条 Seam 或测试专用生产入口；测试跨现有 Interface。
- `py-config-logger` 冻结：业务 Module 文件头获取一次 logger，并在真实事件点直接调用；不支持用户自建 logger wrapper 作为兼容契约。
- WARNING 栈契约：仅 `show_warning_stack=true` 时附当前调用栈，默认关闭；ERROR / CRITICAL / EXCEPTION 始终附栈，存在活动异常时优先 traceback，否则当前调用栈。
- 当前 `sprint02` 的 WARNING/ERROR 栈实现与权威契约存在既有偏差，登记为 `LEGACY-S2-02-01`；S2-02 不修改 `logger.py`、`config.py` 或相关旧测试，也不把偏差合法化。
- raw frame 生命周期：frame 对象不得逃逸，局部引用必须在 `finally` 显式删除。
- 新 caller 测试文件固定为 `tests/01_unit_tests/test_s2_02_caller_info.py`，避免触发当前 `test_tc` 特判。
- 性能门禁固定：baseline 为 `1e6f7c19c6666ec988efb70633166127479e2007`；同机同解释器下 Case A / B 各预热 10,000 次、7 round × 100,000 次，candidate median 均必须低于 baseline median。
- Implementation 完成后必须跑完整项目测试；聚焦测试不能替代全量回归。

下一阶段只能机械展开 `S2-02_方案决策.md` v2，不得在 design-plan 或 implementation 阶段重新选择方案方向。
