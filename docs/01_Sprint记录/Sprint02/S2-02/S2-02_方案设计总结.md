## 冻结摘要

- 生产差量唯一落点：`src/custom_logger/formatter.py::get_caller_info()`。
- Interface 与 Seam 不变：`get_caller_info() -> Tuple[str, int]`；`create_log_line()` 继续直接调用。
- 控制流冻结为 raw frame 单次完整扫描；caller 只选一次，扫描继续只为 `in_test`；不建立 frame 容器。
- 生命周期冻结：只允许局部 `frame/current_frame`，统一 `finally` 显式删除。
- 测试冻结：新增 `test_s2_02_caller_info.py` 8 个聚焦义务；`test_tc0019_call_chain.py` 只改异常注入 seam。
- 性能冻结：baseline `1e6f7c19c6666ec988efb70633166127479e2007`；同脚本、同解释器、双独立进程；10,000 预热、7×100,000；Case A/B candidate median 都必须更低。
- 回归冻结：聚焦、两个只读历史入口、全量项目测试；candidate 有失败时才用 baseline 相同 nodeid 归因。
- Codebase Design 冻结：不新增 Adapter、公共 caller Interface、缓存 Module、第二 Seam 或测试专用生产入口。
- `LEGACY-S2-02-01` 为已知既有偏差，不阻断本设计，但 implementation 不得修复、掩盖或重定义。
- `unapproved_decision_set=[]`；设计阶段未新增业务、架构、owner、失败流、门禁、测试策略或验收选择。

下一阶段必须显式调用 implementation；实现只能按 `S2-02-plan-v1` 机械执行。
